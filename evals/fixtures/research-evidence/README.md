# Research evidence fixture

A small Python/Rust repository for researcher cases. It contains duplicate
names, callback and dynamic registration, conflicting docs, and a chain of
session-storage ADRs. The newest ADR is proposed; an older accepted ADR
matches the current configuration.

Cases ask factual questions and check citations to source-line anchors. The
fixture does not need a build. Passing these cases is a regression signal, not
a measure of production research quality.
