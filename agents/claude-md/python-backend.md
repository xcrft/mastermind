## Quick orientation

- **Language/framework:** Python 3.11 + <FastAPI | Django | Flask>
- **Entry point:** `<src/main.py | manage.py | app.py>`
- **Where business logic lives:** `src/services/` (NOT in the route handlers)
- **Where data models live:** `src/models/`
- **Read-only / generated:** `migrations/`, `*.pb.py`, `vendor/`

## Commands

```bash
# Install deps
uv sync                    # or: pip install -e ".[dev]"

# Run locally
<uvicorn src.main:app --reload | python manage.py runserver | flask run --debug>

# Run tests
pytest                     # full suite
pytest tests/unit -x       # fast loop: unit tests only, stop on first failure
pytest -k "test_name"      # single test

# Lint + typecheck
ruff check .
mypy src/

# Format
ruff format .
```

## Conventions

- **Routes are thin.** Route handlers parse input, call a service, format output. Business logic goes in `src/services/`.
- **Models are dataclasses or Pydantic.** Plain dicts cross module boundaries only with a comment explaining why.
- **No bare `except:`.** Catch specific exceptions. If you need to log-and-reraise, use `logger.exception()`.
- **SQLAlchemy 2.0 style** (if used): `session.execute(select(Model))`, not `session.query(Model)`.
- **Tests live next to code:** `src/services/limiter.py` ↔ `tests/services/test_limiter.py`.

## Database / migrations

- Migrations are autogenerated then **hand-reviewed**. Never apply an unreviewed migration to a non-local DB.
- Schema changes require: migration + backfill plan + rollback note in the PR description.
- Never `DROP COLUMN` in a deploy that also reads the column — split into two deploys.

## Common pitfalls

- **Async/sync mixing.** Don't call sync DB code from an async handler without `run_in_executor`. The interpreter will block the event loop.
- **N+1 queries.** Before merging an endpoint, check the query log. Tools: `django-debug-toolbar`, `sqlalchemy.engine.Engine` logging at DEBUG.
- **Settings via env vars only.** Never hardcode URLs or secrets. Use `pydantic-settings` or `os.environ.get()` with a default in dev only.
- **Time zones.** Always store UTC. Convert at the edge.
