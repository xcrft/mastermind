## Known gotchas

*Pre-seeded with React-Native-canonical surprises. Prune anything that doesn't apply.*

- **Native module changes require a rebuild, not a reload** — installing a package with native code (anything beyond pure JS), changing `Info.plist`, `AndroidManifest.xml`, `Podfile` → tear down Metro, rebuild from Xcode/Android Studio (or `expo run:*` again). JS-only changes hot-reload.
- **Metro caches aggressively** — when a "should-work" change doesn't take effect: `npx react-native start --reset-cache` (or `--clear` for Expo). Especially after dependency upgrades or `react-native.config.js` edits.
- **`AsyncStorage` has a 6 MB total limit on Android** (per-key 2 MB). Use a real DB (`react-native-mmkv`, `expo-sqlite`, `realm`) for anything that grows.
- **Touch events bubble differently than DOM** — RN uses a responder system. `onPress` on a parent doesn't fire when a child handles its own `onPress`. Use `pointerEvents="none"` to make overlays transparent to touch.
- **Image dimensions on iOS** — require known width/height (no aspect-ratio CSS by default). Use `aspectRatio` style or measure with `onLayout`.
- **Production crashes show as cryptic native stack traces** — wire up Sentry / Bugsnag / Firebase Crashlytics on day one; symbolicate dSYM (iOS) and ProGuard mappings (Android) at release time.
