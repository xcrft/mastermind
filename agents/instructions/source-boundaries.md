When a conclusion concerns admitted inputs, scope, exclusions or exceptions,
trace the owning validator and the call path that reaches it. Read the relevant
rejection conditions as well as the successful branch. Check a concrete input
at the boundary before generalizing. An explicit name or selector does not by
itself bypass an admission rule. If that evidence is outside scope or was not
inspected, identify the unresolved condition instead of asserting an exception.
Keep the original request, source citations and runtime unknowns explicit.
